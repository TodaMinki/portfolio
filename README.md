# Сайт-портфолио Минки

Откройте `index.html` в браузере. Сборка, сервер и установка пакетов не нужны.

## Содержимое

Страница содержит профиль Минки, его список технологий и четыре карточки с публичными страницами Weeek, Enma, SavvyCal и Craft. Изображения и ссылки относятся к оригинальным сайтам. Технологии в карточках относятся именно к показанным страницам, а список в «О себе» — к профилю Минки. Карточки не подтверждают участие Минки в разработке этих сервисов.

Для Craft указаны Next.js и Tailwind CSS. На скриншоте DevTools Sources под `www.craft.do` виден путь `/_next/static`, который Next.js использует для своих ресурсов ([документация](https://nextjs.org/docs/app/api-reference/config/next-config-js/assetPrefix)). На втором скриншоте DevTools Elements видны utility-классы с адаптивными префиксами и правила в слое `utilities`, характерные для Tailwind CSS. TypeScript эти скриншоты не подтверждают. Для Weeek указаны JavaScript и SCSS: DevTools Sources показывает собственные файлы сайта в `weeek.net/js`, а Styles — правила из `index.scss`. Фреймворк JavaScript по этим снимкам не определяется. Для SavvyCal указан Tailwind CSS: DevTools Elements показывает адаптивные utility-классы и соответствующие правила в слое `utilities`. Опубликованный стек приложения SavvyCal не подтверждает фреймворк и язык показанной главной страницы. Для Enma указаны React и Tailwind CSS: HTML главной страницы подключает [основной JS](https://www.enma.lol/assets/index-UcmjHrAR.js) с лицензиями React и React DOM и [основной CSS](https://www.enma.lol/assets/index-BiM7ncYZ.css) с сгенерированными `--tw-` переменными и адаптивными utility-классами. По этим ресурсам нельзя установить, использует ли сайт TypeScript.

## Изображения

Для Weeek, SavvyCal и Craft в `assets/` лежат снимки публичных страниц, сделанные 24 сентября 2026 года. Для Enma использовано [превью главной страницы](https://www.enma.lol/homepage.webp), опубликованное самим сайтом; оно оптимизировано и сохранено в WebP. Для замены изображений сохраните те же имена файлов и близкое соотношение сторон:

- `weeek.webp` — Weeek;
- `enma.webp` — Enma;
- `savvycal.webp` — SavvyCal;
- `craft.webp` — Craft.

Контакты и раздел с должностями не показаны, потому что данные для них пока не указаны. Когда появятся реальные ссылки или опыт, их можно добавить в `index.html`.

Стили находятся в `styles.css`. Цвета Monki вынесены в переменные в начале файла. Шрифт Geologica загружается из Google Fonts; если он недоступен, используется системный sans-serif.
